# Security policy

Uke Linux is under active development and has no supported device release yet. Security issues affecting source, build inputs, recovery storage operations, boot integration, package supply chain or diagnostic privacy are in scope for review.

**Report vulnerabilities privately** through [GitHub private vulnerability reporting](https://github.com/MCC45TR/uke-linux/security/advisories/new). Do not put exploit details, device identifiers, credentials, calibration or raw personal logs in a public issue. Reports are triaged against the affected source revision, artifact identity and reproduction steps. We will coordinate a fix and disclosure through the repository advisory workflow.

The four component repositories have private vulnerability reporting enabled as well. Choose the repository that owns the affected code. Ordinary bugs and hardware test results belong in public issues after removing private data.

There are no production builds or security support windows to claim yet. A vulnerability report or source review does not by itself establish hardware impact; the relevant device and artifact are checked separately.
