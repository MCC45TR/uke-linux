# Upstream source archives

Source archives are retained here without modification. Exact revisions and
archive checksums are recorded in `../upstream.tsv` and `../sources.sha256`.
Cutefish is developed by the Cutefish project; this directory is packaging
input, not project-owned desktop source. No upstream acquisition script runs.

The upstream wallpaper archive is retained for research only. Its Unsplash
license is not allowed in Fedora or COPR; it is excluded from the source RPM
and binary package.
