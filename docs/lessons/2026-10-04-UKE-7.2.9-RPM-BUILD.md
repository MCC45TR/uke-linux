  [archive](https://cdn.kernel.org/pub/linux/kernel/v7.x/linux-7.2.9.tar.xz),

  `adc218676eef25575469234709c2d87185ca223a`. The complete local donor log

## UKE-K729-L002 — current subsystem APIs and independent device tree

- **Date:** 2026-10-04.
- **Environment scope:** Upstream Linux 7.2.9 and public Uke donor/OEM source.
- **Evidence class:** Source; device-tree compilation.
- **Status:** Port implementation; physical validation open.
- **Question or previous assumption:** The 6.12 diff could not be applied as a
  valid 7.2.9 implementation without reviewing upstream API changes.
- **Finding:** Initial application stopped on a removed generic eUSB2 PHY path;
  the remaining three-way application exposed 13 conflicts. The port preserves
  current upstream generic PHY/repeater and DWC3 core implementations, converts
  interconnect topology to pointer-linked nodes and ports Uke glue preparation
  to current bulk-clock/DWC3 probe interfaces. Clock, RPMh/regulator, TLMM,
  interconnect, SMMU, USB and DTS changes are exported as seven ordered patches.
  A generated glue edit initially omitted an else-block brace; source review
  corrected it before compiling the RPM candidate.
- **Evidence:** `senemos-uke-kernel/patches/7.2.9/series`, attributed README and
  `manifests/linux-7.2.9.json`. The independent
  `qcom/sm7675-xiaomi-uke.dtb` compiled from the patched 7.2.9 development tree.
- **Practical consequence:** Unsupported donor internals are not silently used
  as current upstream code. The DTS uses Uke CPU/GIC/static reservation evidence;
  it supplies no guessed RAM map or Nabu addresses. Unreviewed peripherals are
  absent or disabled. EFI stub support is configured separately from firmware.
- **Remaining uncertainty:** This DTS is a compile-stage candidate. The future
  UEFI loader must supply exact-profile RAM and dynamic reservations. Storage,
  display, touch, wireless, audio, charging and sensors remain separate bring-up
  tasks; no bootable full-hardware claim follows from this port.
- **Next validation:** Compile every selected port driver, then perform
  profile-specific firmware/handoff review before any eventual tablet test.
- **Supersedes / superseded by:** None; retains earlier baseline limitations.

## UKE-K729-L003 — portable bootstrap, source guards and build scheduling

- **Date:** 2026-10-04.
- **Environment scope:** Fedora Rawhide host; shell contract fixtures.
- **Evidence class:** Host implementation and tests.
- **Status:** Implemented and fixture tested; cross-host tests tracked separately.
- **Question or previous assumption:** A single script must resolve stable

- **Finding:** Seven self-test groups passed, including package-manager command
  fixtures, invalid options/targets, offline profile rejection, missing
  installation privilege, low-disk rejection, invalid patch rejection and real
  signed-source/corrupt-source tests. `latest` and `lastest` both resolve 7.2.9.

## UKE-K729-L004 — package and scheduler trials exposed silent success paths

- **Date:** 2026-10-04.
- **Environment scope:** Fedora Rawhide RPM 6.1, Podman 6.1.2, LLVM 23.1.2.
- **Evidence class:** Failed host/build trials and implementation corrections.
- **Status:** Corrected; full build validation continues separately.
- **Question or previous assumption:** A zero exit status from Git or a
  container state field was sufficient evidence that the intended work occurred.
- **Finding:** RPM rejected a versioned `kernel-uname-r` provide with two
  hyphens; the exact release is now a parenthesized capability. More seriously,
  Git found the surrounding workspace repository when applying patches in RPM's
  extracted tree and silently skipped its relative paths. Config inspection
  exposed missing Uke symbols before that generic build was accepted. `%prep`
  now initializes a local Git root, and required Uke symbols are checked before
  compilation. The SRPM includes the detached signature and pinned public key
  and verifies both SHA-256 and signer before extraction.
  A queued Bash invocation also encountered a parse failure after its entry file
  changed; the POSIX launcher now passes Bash an immutable copy of the program.
  Finally, a low-resource `ninja` process fixture paused the build as intended,
  but Podman reported `Running=false` while `Paused=true`. The original loop
  interpreted this as completion, then cleaned up its own unfinished container.
  The corrected loop treats either field as active and checks expected output.
- **Evidence:** Private failed-trial logs below builder `build/`; source/config
  checks in the RPM spec; the pause fixture observed the paused state. No RPM
  manifest or package success was emitted for these incomplete trials.
- **Practical consequence:** Required config and actual artifacts establish the
  build gate. Interrupted objects remain local and can be retried. Recovery and
  unrelated processes are never paused, killed or cleaned by this scheduler.
- **Remaining uncertainty:** The corrected pause/resume path and complete RPM
  lifecycle still need their subsequent acceptance records.
- **Next validation:** Repeat the bounded pause fixture, finish the actual Uke
  compilation and audit extracted AArch64 packages.
- **Supersedes / superseded by:** Corrects L003's initially unverified scheduler
  resume assumption; its queue and prerequisite fixture findings remain valid.

  refreshed before starting a new clean RPM source build.

  gates. Unresolved API errors are corrected rather than bypassed by disabling

- **Remaining uncertainty:** Individual object compilation does not establish
