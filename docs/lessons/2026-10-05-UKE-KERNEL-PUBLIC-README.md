# 5 October 2026: kernel documentation and stable release maintenance

## UKE-DOC004: a stable upstream release needs an independently reviewed Uke port

- **Lesson ID:** UKE-DOC004
- **Date:** 2026-10-05; live service inspection occurred on 2026-10-04 UTC / 2026-10-05 local time.
- **Environment scope:** Senemos Uke mainline kernel GitHub documentation, source manifests, RPM rules and public COPR metadata.
- **Evidence class:** Source/documentation review, GitHub Markdown rendering and read-only public service inspection.
- **Status:** Public README updated; no new kernel build or physical acceptance performed by this documentation change.
- **Question or previous assumption:** The historical README at commit `9133e4344292237d16b57373ed3b73811cf60947` predated the reviewed Uke profile and package channel. A reader also needed to distinguish future stable source tracking from device support.
- **Finding:** The current default-branch README now explains project status, the four kernel packages, Fedora Rawhide AArch64 delivery, installation/update commands, source builds, provenance, licenses and contribution/security routes. Future stable version lines retain version-specific signed source, patch/configuration, build/package and physical acceptance gates. The existing daily tracking workflow refuses an unreviewed stable profile; it does not replace the port with generic ARM64. RPM installation indexes modules without changing Android partitions or boot selection.
- **Evidence:** Kernel documentation commit `35a4fd7`; README SHA-256 `cc4006adde83cb2541884392ebb90d1c908fdc87de6011b351afcd5f8d89548b`. `make validate` accepted all seven patch and three config identities. Tracked relative documentation links and whitespace/privacy checks passed. GitHub's Markdown API rendered three tables, four shell blocks and six content sections. Live Kernel.org metadata resolved stable `7.2.9`; the COPR API exposed successful `7.2.9-1.2` build [11074500](https://copr.fedorainfracloud.org/coprs/build/11074500) and then-running `7.2.9-1.3` build [11075009](https://copr.fedorainfracloud.org/coprs/build/11075009), with the project limited to `fedora-rawhide-aarch64`. The in-progress build is not an accepted package result.
- **Practical consequence:** Publish current documentation on `main` while preserving the referenced historical commit. Readers can find the [development COPR](https://copr.fedorainfracloud.org/coprs/mcc45tr/uke-linux-test/), exact source profile, build records and environment-specific hardware matrix directly. A maintained stable source policy does not label the development channel as a stable tablet release.
- **Remaining uncertainty:** Public build states change; this inspection is dated. Future stable ports, completed remote packaging revisions, firmware handoff, actual Uke boot and peripheral behavior need their own records. Documentation and rendered HTML are not boot or installation tests.
- **Next validation:** Continue ordered recovery P1 work, collect the independent active COPR build result through the kernel packaging workflow, and admit each future stable version only after its source/port/package checks.
